# MasterMind — установка и краткое руководство

MasterMind — плагин для мастер-шины в стиле modern metal (VST3, Windows 64 бит). Он измеряет звук («глаза»), обрабатывает его десятью модулями и помогает сравнивать трек с референсами и с остальными песнями альбома.

## Установка

1. Закройте REAPER.
2. Скопируйте файл `MasterMind.vst3` в папку `C:\Program Files\Common Files\VST3\`. Windows попросит права администратора: нажмите «Продолжить». Старый файл замените.
3. Запустите REAPER.
4. Options → Preferences → Plug-ins → VST → кнопка **Re-scan**.
5. Добавьте плагин на мастер: FX → **MasterMind** (desNotto). Ставьте его последним в цепочке мастера.

## Первые шаги

1. Включите воспроизведение. Анализ сбрасывается при каждом старте (флажок **Reset on play** справа).
2. Вкладка **Eyes** показывает всё сразу: тональный баланс, громкость, низ, стерео и список **Checks**. Красные и жёлтые строки — что исправить сначала. Наведите курсор на строку: появится совет.
3. Вкладка **Master**: спектр и все модули. По умолчанию модули выключены, звук проходит без изменений. Зелёная точка в заголовке модуля включает его.
4. Наведите курсор на любую ручку или кнопку и подождите полсекунды: появится подсказка с советом.
5. Двойной клик по ручке сбрасывает её. Shift при движении — точная настройка. Правый клик по ручке — ввод числа.
6. Двойной клик по имени модуля открывает все его параметры.

## Референсы (кнопки 1–6 вверху)

- Клик по пустой кнопке (или перетаскивание файла WAV, FLAC, MP3, OGG) загружает референс. Плагин анализирует весь файл за несколько секунд.
- Референсы из набора (точка в углу кнопки) задают цель и голубой «коридор» на спектре и в тональном балансе.
- **A/B**: A — ваш трек, B — выбранный референс с выровненной громкостью. Правый клик по кнопке — пауза, громкость, исключение из набора.
- **Match EQ** (справа над спектром) предлагает до 8 мягких фильтров к цели. Ничего не меняется, пока вы не нажмёте Apply. Undo возвращает всё обратно.

## Мониторинг (блок Monitor вверху)

- Коррекция наушников или колонок (файл AutoEQ/REW .txt или импульс .wav), имитация систем (ноутбук, телефон, машина…), прослушивание Mono, Mid, Side, полос и разницы.
- Пока что-то из этого включено, окно обведено красным и горит **MONITOR ON**.
- Мониторинг влияет только на то, что вы слышите. При офлайн-рендере плагин выключает его сам. Перед рендером в реальном времени выключите его вручную.
- **Bypass** с **Match** сравнивает обработку с исходником при одинаковой громкости.

## Альбом (вкладка Album)

1. Нажмите **New album...** и выберите папку. Все копии плагина в разных проектах могут работать с одним файлом.
2. Проиграйте песню целиком и нажмите **Store passport**.
3. Повторите для каждой песни. Таблица покажет, какая песня громче, светлее или уже остальных. Правый клик по строке: якорный трек, снимок цепочки.

## Пресеты

Стрелки ‹ › листают пресеты, список открывает заводские и ваши пресеты, а также Rename, Delete, Import и Export. Звёздочка * — пресет изменён и не сохранён.

## Где лежат файлы

`%APPDATA%\MasterMind\`: `settings.json` (размер окна, язык, настройки анализа), `presets\` (ваши пресеты), `translation\` (имитации систем, их можно править), `refcache\` (кэш анализа референсов). Шестерёнка внизу справа открывает эту папку, переключает язык (English / Русский) и качество.

## Удаление

Удалите `C:\Program Files\Common Files\VST3\MasterMind.vst3` и при желании папку `%APPDATA%\MasterMind\`.

## Версия

Номер версии и код сборки показаны внизу окна. Сообщая о проблеме, пишите эти два значения.
